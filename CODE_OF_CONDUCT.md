# Code of Conduct

## Our Standard

This project expects respectful, constructive, and professional collaboration.

Examples of positive behavior include:

- giving actionable technical feedback
- assuming good intent while discussing tradeoffs
- focusing criticism on code, behavior, or decisions rather than people
- helping keep the repository welcoming to new contributors

Examples of unacceptable behavior include:

- harassment, insults, or personal attacks
- discriminatory or exclusionary language
- repeated bad-faith arguments or deliberate disruption
- publishing private information without permission

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, commits, code, wiki edits, or other contributions that violate this code of conduct.

## Reporting

For general conduct concerns, contact the repository maintainer privately. For security concerns, follow `SECURITY.md`.
