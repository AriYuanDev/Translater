# 快译 - Chrome 划词翻译扩展

一个简洁高效的 Chrome 翻译插件，支持双击翻译单词、选中文本悬浮翻译和本地朗读功能。

## ✨ 功能特性

### 1. 双击翻译单词
- 双击任意英文单词，立即显示翻译弹窗
- 显示 **IPA 格式美式音标**（如 `/həˈloʊ/`）
- 支持词性、释义和例句展示
- 自动朗读单词发音

### 2. 选中文本悬浮按钮
- 鼠标选中任意文本后，右侧出现悬浮按钮
- **【译】按钮**：翻译选中内容为中文
- **【🔊】按钮**：使用 TTS 朗读选中内容

### 3. 本地朗读 (无需网络)
- 使用 Web Speech API 实现本地 TTS
- 美式英语发音
- 无需任何网络连接

## 🚀 安装方法

1. 打开 Chrome 浏览器，访问 `chrome://extensions/`
2. 开启右上角的 **「开发者模式」**
3. 点击 **「加载已解压的扩展程序」**
4. 选择此项目文件夹 `Translater`
5. 安装完成！

## 📖 使用说明

### 翻译单词
1. 在任意网页上**双击**一个英文单词
2. 弹窗显示单词释义、音标
3. 点击弹窗右上角的 🔊 按钮朗读

### 翻译句子/段落
1. 用鼠标**选中**要翻译的文本
2. 在选中区域旁边会出现悬浮按钮
3. 点击 **「译」** 翻译成中文
4. 点击 **「🔊」** 朗读选中内容

### 关闭弹窗
- 点击弹窗右上角的 ✕ 按钮
- 或点击页面其他任意位置

## 🔧 技术实现

| 功能 | 技术方案 | 网络需求 |
|------|---------|---------|
| 单词翻译 | dictionaryapi.dev | 需要 |
| 句子翻译 | Google Translate | 需要 |
| 朗读 (TTS) | Web Speech API | **本地** |
| 音标显示 | IPA 格式美式音标 (dictionaryapi.dev) | 需要 |

## ⚠️ 注意事项

1. **首次使用**可能需要刷新页面
2. 翻译功能需要**网络连接**
3. 朗读功能使用系统 TTS，**无需网络**
4. 部分网站可能禁用内容脚本注入
